# RANA Lab website source

This is a self-contained static website. Edit `index.html` in a text editor such as VS Code. It has no build step or external packages.

## Publish with GitHub Pages

1. Create or open the GitHub repository where you want the lab website.
2. Put `index.html` in the repository root (the top-level folder).
3. Commit and push the file to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then choose `main` and `/(root)`, and save.
6. After GitHub finishes deploying, the Pages URL appears in that same section.

The multilingual selector and presentation filters are implemented in the HTML file.
